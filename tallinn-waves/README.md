# Tallinn Sunset Waves

Интерактивная визуальная композиция на **p5.js**, опубликованная через GitHub Pages.

Проект создаёт полноэкранную анимацию с атмосферой заката над Таллинном:

- градиентное небо с переходом от тёмно-фиолетового к тёплым оранжево-жёлтым оттенкам;
- солнце с мягким свечением, которое медленно движется по дуге от восхода к закату и затем повторяет цикл;
- стилизованный силуэт Старого Таллинна с холмом Тоомпеа, крепостными башнями и характерными шпилями;
- несколько слоёв анимированных волн с индивидуальными цветовыми градиентами;
- интерактивность: при наведении мыши на область волн их амплитуда плавно увеличивается;
- адаптация canvas к размеру окна браузера.

## Файлы

- `index.html` — HTML-страница проекта. Подключает p5.js 1.9.4 через CDN и основной скрипт `tallinn-waves.js`.
- `tallinn-waves.js` — основной p5.js-скетч: параметры оформления и анимации, градиент неба, солнце, силуэт города и интерактивные волны.

## Настройка

Основные параметры собраны в объекте `CONFIG` в начале `tallinn-waves.js`. Там можно изменять цвета неба, солнца и волн, размеры и положение солнца, количество и амплитуду волн, их частоту, скорость и расстояние между слоями.

Проект рассчитан на запуск непосредственно в браузере или в редакторе [p5.js](https://p5js.org/).
